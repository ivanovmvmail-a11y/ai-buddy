# 002 — Поиск по документам команды

| Поле | Значение |
|---|---|
| Статус | черновик (реализация и тесты в этом PR, ожидает ревью) |
| Автор | Codex |
| Связано | ТЗ: поиск по документам и недоступность чужих данных; контракт `app.rag.retrieve` |

## 1. Зачем
Стажёр получает выдержки из общих документов и документов своей команды.
Внутренние документы другой команды не попадают ни в ответ, ни в контекст модели.

## 2. Пользователи и роли
Для всех ролей действует одно правило: `team IS NULL` либо точное совпадение с `user.team`.
HR, куратор и руководитель не получают исключений для поиска документов.

## 3. Сценарий
1. Оператор загружает markdown-документы, явно задав команду или `null` для общего документа.
2. Загрузчик разбивает текст на ограниченные по длине фрагменты, считает векторы 1024 и
   атомарно заменяет документ с его фрагментами по стабильному `source_id`.
3. `retrieve(query, user, k=4)` векторизует запрос, фильтрует доступные документы до top-k
   и возвращает `{title, content, url}` для найденных фрагментов.

Пустой запрос, `k <= 0`, отсутствие базы или документов дают `[]`.
Ошибка настроенной базы/эмбеддера передаётся вызывающему коду: поиск не расширяет доступ.

## 4. Поведение агента
Контракт и промпт не меняются. Документы содержат справочные данные, без инструкций для ИИ.
Поддельный детерминированный эмбеддер используется в тестах и демо до подключения GigaChat Claude.

## 5. Данные и хранение
10 синтетических markdown-файлов: 4 общих, по 3 для «Платформы объявлений» и «Авито Доставки».
PostgreSQL + pgvector, прямое подключение psycopg по `DATABASE_URL`, без Supabase API/ролей.
SQL ограничивает команду до `LIMIT`. Дополнительная RLS для непривилегированного читателя
использует транзакционный `app.rag_team`; владелец/суперпользователь обходят RLS PostgreSQL,
поэтому явный фильтр обязателен. Загрузчик работает от владельца таблиц.

## 6. Интерфейс
Существующий агент получает список источников без новых полей. Для загрузки — CLI из backend.

## 7. Критерии приёмки
- **AC-1.** Иван из «Авито Доставки» никогда не получает внутренние документы «Платформы объявлений», даже по точному тексту и при большом k.
- **AC-2.** Каждая демо-роль получает общие документы и только документы своей команды; фильтр применяется до top-k.
- **AC-3.** Загрузка считает нормированные векторы 1024, возвращает ограниченные фрагменты и сохраняет исходный текст без метаданных.
- **AC-4.** Повторная загрузка заменяет старые фрагменты и команду, без дубликатов; ошибка эмбеддера оставляет предыдущую версию.
- **AC-5.** Пустой запрос/хранилище и отсутствие базы не вызывают сетевых запросов; неисправность настроенного сервиса не скрывается.
- **AC-6.** Миграция работает на чистом PostgreSQL с pgvector; SQL параметризован, RLS-контекст локален транзакции.

## 8. Метрики
Автотесты проверяют изоляцию всех демо-пользователей; покрытие backend ≥ 80%.
Качество семантического ранжирования оценивается после подключения настоящего эмбеддера.
