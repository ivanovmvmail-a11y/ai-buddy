## 1. Зачем
Жюри нужно доказательство качества, а не «посмотрите, как красиво отвечает». Набор фиксированных вопросов с
проверяемыми ожиданиями показывает точность поиска, долю ответов с источником, правильные отказы и — главное —
**ноль утечек** чужих данных. Набор же ловит регрессии: при разработке он поймал поломку сценарного режима и
выдумки модели.

## 2. Состав (`backend/golden/cases.json`, 37 вопросов)
| Категория | Сколько | Что проверяем |
|---|---|---|
| Ответ по документам | 12 | правильный документ в источниках, ответ не «нет в базе» |
| Ловушки: чужая команда, чужой план | 8 | ни одной фразы из чужих документов/плана в ответе и источниках; явный отказ на чужой план |
| Нет в базе | 5 | честное «нет в документах» + к кому идти (вопросы эксперта: ноутбук, красный пайплайн, запуск сервиса) |
| HR BP | 3 | отпуск, больничный, отгул → к HR BP |
| План и следующий шаг | 5 | следующий шаг, кого ждём, наставник видит план своего стажёра, заявки на одобрение |
| Действия | 4 | только черновик, заявка в сервисе **не** создана; у роли без права черновика нет |

Типичные вопросы взяты из вебинара эксперта (репозиторий, pull request, ревью, пайплайн, запуск, доступы,
ноутбук, отгул). Вопросы, на которые в демо-документах нет ответа, — честно в категории «нет в базе».

## 3. Как работает
Каждый вопрос проходит весь путь, как в интерфейсе: `/chat` → агент → модель → инструменты (права, черновики)
→ поиск по демо-документам (в памяти, «по словам»). Состояние сервисов сбрасывается перед каждым вопросом.
Критерии — проверяемые строки и структуры ответа, без оценки «на глаз».

## 4. Запуск
```bash
cd backend && uv run python -m golden.run                       # сценарный режим, без ключей
cd backend && uv run python -m golden.run --provider gigachat   # с моделью, ключ в backend/.env
```
Отчёты: [`docs/golden-report.md`](../../golden-report.md) (сценарный режим),
[`docs/golden-report-gigachat.md`](../../golden-report-gigachat.md) (GigaChat). В CI набор в сценарном режиме
проходит при каждом PR (`backend/tests/test_golden.py`): любой провал или утечка роняет проверку.

## 5. Ограничения
- Модель отвечает не детерминированно: отчёт GigaChat — один прогон; при повторе возможны единичные провалы.
- Поиск без ключа сравнивает формы слов грубо; документы и вопросы — синтетические.
