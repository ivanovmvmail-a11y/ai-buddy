# SDD-спецификации AI-buddy

ТЗ требует вести разработку AI-функций по SDD (spec-driven development) и приложить спецификации к сдаче.
Формат свой, по мотивам spec-kit / OpenSpec: **сначала спецификация → потом код и тесты по ней**.

## Как работаем
1. Новая AI-функция (сценарий, инструмент агента, изменение промпта) начинается с файла `docs/specs/<NNN>-<slug>.md`
   по шаблону [`_template.md`](_template.md). Статус `черновик`.
2. Спецификацию ревьюят люди (PR), статус → `принята`.
3. Код и тесты пишутся по ней. Каждый критерий приёмки (`AC-…`) закрыт хотя бы одним автотестом —
   в таблице «Трассировка» указано, каким. Статус → `реализована`.
4. Меняется поведение — сначала правим спецификацию, потом код (в том же PR).

## Нумерация
- `0xx` — платформа агента (механика, безопасность, общие правила).
- `1xx` — сценарии стажёра.
- `2xx` — сценарии наставника, руководителя, HR BP, куратора.
- `3xx` — фоновые процессы (ИИ-крон, аналитика).
