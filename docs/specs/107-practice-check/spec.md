## 1. Зачем
У пункта плана есть «задание на практике», но это одна строчка без проверки. Эксперт на вебинаре: не «получи доступ»,
а «сделай и покажи результат». Стажёр сдаёт ответ своими словами — бот сверяет его с ключевыми фактами учебного
документа и подсказывает, чего не хватает, не выдавая готовый ответ. Работает без ключа ИИ.

## 2. Пользователи и роли
| Роль | Что видит / делает |
|---|---|
| Стажёр | у своего незакрытого пункта с проверяемым заданием — «Сдать задание», поле ответа, «Проверить» |
| Остальные | кнопки нет; `POST …/practice` — 404 (чужой пункт и пункт без проверки неотличимы) |

## 3. Сценарий
1. Аня у «Практикум: Git» нажимает «Сдать задание», пишет, что сделала.
2. Бот сверяет ответ с фактами документа «Учебный репозиторий — клонирование и ветки»: ветка, коммит, push, PR.
3. Не хватает фактов → «Почти. Подумай: как изменения попадают на сервер? …» и ссылка на документ.
4. Все факты есть → «Задание выполнено: …. Можно отметить пункт «Готово»». Пункт стажёр закрывает сам; закрытые пункты
   темы уже ведут к предложению наставнику поднять уровень (спека 202) — решает человек.

### Ошибки
- Пустой ответ — кнопка «Проверить» неактивна; длиннее 2000 символов — 422.
- Ответ короче 15 символов — не засчитывается: «опиши подробнее».

## 4. Поведение агента
Модель не участвует: проверка — `backend/app/agent/practice.py`, факты — варианты слов для каждого пункта. Это проверка
задания, а не оценка человека: уровень не меняется, текст ответа не сохраняется.

## 5. Данные
Задания привязаны к тексту `practice` из seed (Codex): «Создай учебную ветку, коммит и pull request» (Практикум: Git),
«Найди упавший шаг учебного пайплайна и опиши проверку исправления» (Практикум: CI), «Опиши, почему нельзя сразу выдать
зарегистрированную посылку» (Разобрать документы Авито Доставки). Тест сверяет, что каждый ключ есть в seed.

## 6. Интерфейс
Форма под пунктом: текст задания, поле ответа, «Проверить» / «Закрыть»; результат — зелёный («выполнено») или жёлтый
(«почти») блок с документом-источником.

## 7. Критерии приёмки
- **AC-1.** Полный ответ → `passed: true`, текст предлагает «Готово», источник — документ пункта.
- **AC-2.** Частичный ответ → `passed: false`, засчитанные факты и подсказки-вопросы, без готового ответа.
- **AC-3.** Чужой пункт, не стажёр, пункт без проверки → 404; пустой или длинный ответ → 422.
- **AC-4.** В событиях — `practice_checked` с `passed`, без текста ответа.
- **AC-5.** Кнопка видна только стажёру у пункта с `practice_check`.

## 8. Метрики
Событие `practice_checked`: доля засчитанных с первой попытки по темам — где учебный документ непонятен.
