# 201 — Экран наставника: план реализации

## 1. Подход
Только интерфейс: все данные уже отдают эндпоинты спеки 101 (`/interns`, `/plan`, `/profile/skills`,
`/plan/summary`). Компонент `frontend/src/components/InternCards.tsx` показывается над планом для наставника,
руководителя и куратора; права проверяет сервер, интерфейс не запрашивает карту навыков у ролей без доступа.

## 2. Что меняется
| Часть | Файлы | Зона |
|---|---|---|
| Интерфейс | `InternCards.tsx`, `PlanPanel.tsx`, `lib/api.ts`, `lib/queries.ts`, `lib/types.ts` | Claude |
| Тесты | `frontend/src/__tests__/mentor.test.tsx`, поддельный `/plan/summary` | Claude |

## 3. Данные и контракты
`GET /plan/summary?intern_id=&week=` — без изменений (docs/API.md). Неделя = `ceil(день / 7)`.

## 4. Проверка
Vitest на поддельном сервере (AC-1…AC-6) + проверка в браузере с настоящим backend.

## 5. Риски
«Частые темы» требуют событий чата — перенесены в спеку 302.

## 6. Что заменяется при внедрении в Авито
Ничего: экран читает те же сервисы через API.
