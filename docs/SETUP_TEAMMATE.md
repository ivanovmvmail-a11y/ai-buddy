# Настройка для тиммейта: Codex на сайте ChatGPT

Устанавливать ничего не нужно. Codex работает на сайте **chatgpt.com/codex**: сам берёт наш код с GitHub,
пишет изменения и открывает Pull Request. Ключи (GigaChat, Supabase) тебе тоже не нужны.

---

## Шаг 1. Принять приглашение в репозиторий (1 минута)
1. Открой https://github.com/ivanovmvmail-a11y/ai-buddy/invitations (войди в свой GitHub, если попросит).
2. Нажми **Accept invitation**.

## Шаг 2. Подключить GitHub к Codex (3 минуты)
1. Открой **https://chatgpt.com/codex** и войди своим аккаунтом ChatGPT.
2. Нажми **Connect to GitHub** (или **Подключить GitHub**) и нажми **Authorize** на странице GitHub.
3. GitHub спросит, к каким репозиториям дать доступ. Выбери **ai-buddy** (`ivanovmvmail-a11y/ai-buddy`).
   - Если **ai-buddy нет в списке**: репозиторий принадлежит Виктору, поэтому подключение может
     потребовать его одобрения. Нажми **Request** (Запросить), если есть такая кнопка, и напиши Виктору.
     Он одобрит запрос в письме от GitHub или в настройках: GitHub → Settings → Applications.

## Шаг 3. Создать окружение (3 минуты)
Окружение — это «виртуальный компьютер», на котором Codex запускает наш проект.

1. На chatgpt.com/codex открой **Settings → Environments** (Настройки → Окружения) → **Create environment**.
2. **Repository:** выбери `ivanovmvmail-a11y/ai-buddy`.
3. **Name:** `ai-buddy`.
4. Найди поле **Setup script** (скрипт установки) и вставь туда:
   ```bash
   command -v uv || pip install uv
   cd backend && uv sync && cd ..
   cd frontend && npm ci && cd ..
   ```
5. **Environment variables** (переменные окружения): добавь одну переменную
   `LLM_PROVIDER` = `echo`. Это тестовый режим без ключей.
6. **Agent internet access** (доступ в интернет): оставь **Off** (выключен).
7. Нажми **Create environment** / **Save**.

## Шаг 4. Включить автоматическое ревью (1 минута, по желанию)
**Settings → Code review** → включи ревью для репозитория **ai-buddy**.
Тогда Codex сам будет проверять каждый Pull Request, в том числе от Claude.

## Шаг 5. Первое сообщение Codex
На главной chatgpt.com/codex выбери окружение **ai-buddy**, ветку **main**, вставь текст ниже
и нажми кнопку **Ask** (не Code: сейчас нужно только почитать и объяснить).

```
Привет! Я не программист, объясняй мне всё простыми словами на русском.
Прочитай AGENTS.md, .ai/STATUS.md, .ai/claude-log.md, .ai/codex-log.md, .ai/HANDOFF.md,
docs/SPEC.md и docs/API.md. Коротко расскажи: что это за проект, за что отвечаешь ты (Codex),
за что отвечает Claude и какие правила мы соблюдаем. Ничего не меняй.
```

---

## Как работать дальше (каждая задача)

1. На chatgpt.com/codex выбери окружение **ai-buddy** и ветку **main**.
2. Напиши задачу и нажми **Code** (когда нужно изменить код) или **Ask** (когда нужно только спросить).
   Шаблон задачи:
   ```
   Задача: <что сделать, своими словами>.
   Соблюдай AGENTS.md: работай только в своей зоне, в том же изменении обнови
   .ai/codex-log.md и свою строку в .ai/STATUS.md. Объясни мне простыми словами, что ты сделал.
   ```
3. Когда Codex закончит, посмотри его объяснение и нажми **Create PR** (Создать PR).
4. Напиши Виктору ссылку на PR. Claude его проверит, а Виктор смержит.

Если нужно что-то поправить в уже созданном PR, напиши об этом Codex в той же задаче
и нажми **Update PR** / **Push changes**.

## Важно
- Ключи и пароли Codex не нужны. **Никогда не вставляй их в чат Codex.**
- Изменения базы данных Codex пишет файлами в `supabase/migrations/`. Применяет их к базе Claude после проверки.
- Codex на сайте не может показать живой сайт. Его можно будет посмотреть по ссылке после деплоя, её даст Виктор.
