# Настройка для тиммейта: Codex на сайте ChatGPT

Устанавливать ничего не нужно. Codex работает на сайте **chatgpt.com/codex**: сам берёт наш код с GitHub,
пишет изменения и открывает Pull Request. Ключи (GigaChat, Supabase) тебе тоже не нужны.

> ✅ У Екатерины всё уже настроено (8 ноября). Эта инструкция — на случай, если понадобится повторить.

---

## Шаг 1. Принять приглашение в репозиторий
Открой https://github.com/ivanovmvmail-a11y/ai-buddy/invitations → **Accept invitation**.

## Шаг 2. Открыть Codex и подключить GitHub
1. Открой **chatgpt.com/codex**. Если открылась рекламная страница, нажми **«Перейти в Cloud»** справа вверху.
2. Под полем ввода нажми **«Среда по умолчанию»** → подключить GitHub → на GitHub **Authorize** →
   **Only select repositories** → **ai-buddy** → **Install**.
   Если ai-buddy нет в списке, напиши Виктору: ему нужно одобрить доступ в письме от GitHub.

## Шаг 3. Создать среду
1. Там же создай среду для репозитория `ivanovmvmail-a11y/ai-buddy` → **«Начать настройку»**.
   Codex сам проверит проект (установка, сборка, тесты). Подожди, пока он закончит.
2. Если он напишет, что не смог сохранить конфигурацию, нажми **«Редактировать среду»** и заполни вручную:
   - **Скрипт установки** (карандаш ✏️):
     ```bash
     command -v uv || pip install uv
     cd backend && uv sync && cd ..
     cd frontend && npm ci && cd ..
     ```
   - **Навык для запуска** — не трогать.
   - **Доступ ко всему интернету** — выключен. **Домены менеджеров пакетов** — включены.
   - **Переменные среды** → Управление → ключ `LLM_PROVIDER`, значение `echo` → Сохранить
     (необязательно: этот режим и так включён по умолчанию). Настоящие ключи сюда **не вставлять**.
3. Нажми **«Сохранить черновик»**, затем **«Опубликовать»** (без черновика кнопка неактивна).
   Внизу должно появиться «Все изменения сохранены».

## Шаг 4. Включить автоматическое ревью (по желанию)
В настройках Codex найди **Code review** и включи его для **ai-buddy**.

## Шаг 5. Первое сообщение Codex
**«Новый чат»** → над полем ввода должно быть **«Облако»** и **ai-buddy** → вставь текст и нажми синюю стрелку ↑:
```
Привет! Я не программист, объясняй мне всё простыми словами на русском.
Прочитай AGENTS.md, .ai/STATUS.md, .ai/claude-log.md, .ai/codex-log.md, .ai/HANDOFF.md,
docs/SPEC.md и docs/API.md. Коротко расскажи: что это за проект, за что отвечаешь ты (Codex),
за что отвечает Claude и какие правила мы соблюдаем. Ничего не меняй.
```

## Как работать дальше (каждая задача)

1. **«Новый чат»** → проверь, что выбрана среда **ai-buddy** (и ветка **main**, если есть выбор).
2. Напиши задачу по шаблону и нажми ↑:
   ```
   Задача: <что сделать, своими словами>.
   Соблюдай AGENTS.md: работай только в своей зоне, в том же изменении обнови
   .ai/codex-log.md и свою строку в .ai/STATUS.md. Объясни мне простыми словами, что ты сделал.
   ```
   Если нужно только спросить, без изменений, допиши в конце «Ничего не меняй».
3. Когда Codex закончит, прочитай его объяснение и нажми **«Создать PR»** (Create PR).
4. Скинь Виктору ссылку на PR. Claude его проверит, а Виктор смержит.

Нужно поправить уже созданный PR? Напиши Codex об этом в том же чате и обнови PR кнопкой под ответом.

## Важно
- Ключи и пароли Codex не нужны. **Никогда не вставляй их в чат или в настройки среды.**
- Изменения базы данных Codex пишет файлами в `supabase/migrations/`. Применяет их к базе Claude после проверки.
- Живой сайт Codex не показывает. Его можно будет посмотреть по ссылке после деплоя, её даст Виктор.
- **Одобрение PR от Claude.** Когда Виктор пришлёт ссылку на PR: **Files changed** → **Review changes** → **Approve** → **Submit review**.
