# SPEC — спецификация AI-buddy

_Заполняется после выхода ТЗ через `/jmo-workflow:interview`._

## Что известно до ТЗ
Трек Web/AI от Авито: прототип ИИ-помощника, который помогает стажёру быстрее освоиться в новой команде и приступить к работе. Должен учитывать особенности команды и взаимодействовать с корпоративными сервисами, экономя время стажёра и наставника.

Пример стека от организаторов: Python/Go, JS/TS, React, LLM, RAG, MCP, PostgreSQL, Docker.

## Гипотезы (проверить по ТЗ)
- RAG по документам команды (онбординг, регламенты, архитектура, глоссарий).
- MCP-инструменты к мок-сервисам: трекер задач, вики, календарь, контакты наставника/команды.
- План онбординга по дням + чек-лист прогресса; сводка для наставника.
