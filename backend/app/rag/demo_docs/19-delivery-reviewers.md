# Авито Доставка: кого звать на ревью

Внутренняя синтетическая договорённость команды «Авито Доставка».

## Кого звать на ревью
Учебные PR проверяет наставник. Если изменение затрагивает статусы
отправления, наставник подключит участника команды, который ведёт тему статусов.
В описании PR обязательно укажи сценарий проверки, например «Мятная посылка».

## Сколько ждать ревью
Ждать ревью нужно не дольше двух рабочих дней, как в общем регламенте. Если ответа нет,
напомни ревьюеру в канале команды и продолжай следующий пункт плана.
