# Авито Доставка: запуск сервиса локально

Внутренняя синтетическая инструкция команды «Авито Доставка». Учебный сервис
маршрутов не связан с реальными тарифами и адресами.

## Как запустить сервис локально
Склонируй репозиторий учебного сервиса маршрутов и создай локальный файл настроек
по примеру. Запусти сервис командой из README: она поднимает сервис и учебную очередь
событий. Проверь, что маршрут «Северный маяк» строится между пунктами «Сосна» и «Облако».

## Тестовые данные
Тестовые отправления создавай только с вымышленными идентификаторами. После
экспериментов очисти очередь событий, чтобы повторная обработка не путала результаты.

## Если не запускается
Сохрани текст ошибки и последнее событие из очереди и покажи их наставнику.
