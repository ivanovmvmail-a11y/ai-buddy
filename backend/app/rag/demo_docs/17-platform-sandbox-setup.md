# Платформа объявлений: как поднять песочницу

Внутренняя синтетическая инструкция команды «Платформа объявлений».

## Как поднять песочницу
Песочница — личная копия учебного стенда «Бумажный каталог». Попроси наставника
включить её для тебя, затем запусти сброс к начальному набору карточек. Проверь,
что поиск по заголовку находит «воздушный змей»: это и есть smoke-тест песочницы.

## Правила песочницы
В песочнице можно ломать что угодно: она сбрасывается одной командой. Перед показом
результата наставнику восстанови начальный набор карточек и запиши, что проверил.
