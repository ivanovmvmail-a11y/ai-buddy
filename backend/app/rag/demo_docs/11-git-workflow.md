# Учебный репозиторий: клонирование и ветки

Синтетическая инструкция учебного проекта, а не реальный регламент компании.

## Как склонировать репозиторий
Сначала дождись выдачи доступа к пространству команды в учебном Bitbucket. Открой
репозиторий своей команды и скопируй адрес для клонирования. В терминале выполни
`git clone <адрес>` и перейди в созданную папку. Если клонирование просит пароль,
не вводи рабочий пароль в терминал: проверь, что заявка на доступ одобрена, и спроси наставника.

## Как завести ветку
Каждая задача делается в своей ветке. Обнови основную ветку командой `git pull`,
затем создай ветку `git checkout -b <номер-задачи>-<коротко-о-задаче>`. Делай небольшие
коммиты с понятным сообщением: что изменилось и зачем.

## Как отправить изменения
Отправь ветку командой `git push -u origin <имя-ветки>` и открой PR в основную
ветку. Прямо в основную ветку учебного репозитория ничего не отправляется. Если git
сообщает о конфликте, не удаляй чужие изменения: покажи конфликт наставнику.
