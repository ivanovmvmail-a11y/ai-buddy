# Статусы учебного отправления

Внутренняя синтетическая заметка команды «Авито Доставка».

Отправление в упражнении последовательно проходит статусы «зарегистрировано»,
«принято», «в пути», «готово к выдаче» и «выдано». До приёма его можно отменить.
Попытка выдать отправление прямо из регистрации возвращает учебную ошибку перехода.

Сценарий «Мятная посылка» проверяет успешную цепочку и повторную обработку события
приёма: повтор не должен создавать новое отправление. Имена сценариев и правила
придуманы для демонстрации, реальные интеграции здесь не используются.

Если ожидание теста расходится с поведением стенда, уточни правило у наставника.
