# Глоссарий стажировки

Синтетические определения для учебного проекта.

- **Buddy, наставник** — коллега, который помогает разобраться в задачах и процессах.
- **Онбординг** — знакомство с командой, инструментами и ожиданиями от стажировки.
- **Бэклог** — упорядоченный список задач, из которого команда выбирает следующую работу.
- **Pull request, PR** — предложение изменений кода с обсуждением и проверками.
- **Код-ревью, code review** — проверка изменения другим участником команды перед слиянием.
- **CI, пайплайн** — автоматические проверки, которые запускаются на каждый pull request: сборка, линтер и тесты. Зелёный пайплайн — проверки прошли, красный — что-то упало.
- **OKR** — цели и ключевые результаты команды на квартал. Цели своей стажировки стажёр обсуждает с руководителем на первой неделе.
- **Стенд** — отдельная среда для проверки учебного решения.
- **Smoke-тест** — быстрая проверка основных функций после изменения.
- **Критерии готовности** — наблюдаемые условия, при которых задачу можно завершить.
- **Ретроспектива** — встреча для обсуждения улучшений рабочего процесса.
