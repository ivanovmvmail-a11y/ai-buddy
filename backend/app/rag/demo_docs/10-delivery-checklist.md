# Разбор учебной ошибки маршрута

Внутренний синтетический чек-лист команды «Авито Доставка».

Для упражнения «Бирюзовый пакет» подготовь отправление между вымышленными пунктами.
Проверь исходный статус, выбранный маршрут и последнее событие обработки.
Сравни фактическую последовательность с ожидаемой цепочкой статусов.

В отчёте для наставника укажи шаги воспроизведения, ожидаемый результат и результат
повторной проверки после исправления. Идентификаторы должны относиться только
к учебному стенду. Заверши разбор короткой заметкой о том, какая проверка позволит
раньше заметить похожую ошибку в следующем учебном задании.
