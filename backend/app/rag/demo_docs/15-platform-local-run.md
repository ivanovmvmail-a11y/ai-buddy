# Платформа объявлений: запуск сервиса локально

Внутренняя синтетическая инструкция команды «Платформа объявлений». Сервис
«Бумажный каталог» учебный и не связан с реальными системами.

## Как запустить сервис локально
Склонируй репозиторий учебного каталога и скопируй файл с примером настроек в
локальный файл настроек. Запусти сервис одной командой из README репозитория:
она поднимает каталог и учебную базу карточек. Сервис готов, когда страница
проверки здоровья отвечает статусом «ok».

## Тестовые данные
После первого запуска загрузи начальный набор вымышленных объявлений: воздушный змей,
настольная лампа, деревянный конструктор. Их можно сбросить в любой момент: это
учебные данные.

## Если не запускается
Чаще всего занят порт или не заполнены настройки. Сохрани текст ошибки и покажи
наставнику вместе с командой, которую запускал.
