# Платформа объявлений: учебный стенд

Внутренний синтетический документ учебной команды «Платформа объявлений».
Стенд «Бумажный каталог» не связан с реальными системами или пользователями.

## Начало работы
Наставник выдаёт набор вымышленных объявлений: воздушный змей, настольная лампа,
деревянный конструктор. У каждого есть заголовок, категория и учебный статус.
Для первой задачи достаточно проверить переход из черновика в опубликованное состояние.

## Проверка
Перед демонстрацией восстанови начальный набор карточек и запусти проверку поиска
по заголовку. Ожидаемый результат фиксируется в учебной задаче. Случайные ошибки
стенда записываются с временем и идентификатором тестового объявления.
