# Состояния учебной карточки

Внутренняя синтетическая заметка команды «Платформа объявлений».

В демонстрационной модели карточка проходит состояния «черновик», «проверка»,
«опубликовано» и «архив». На проверку принимается только карточка с заголовком
и категорией. Архивная карточка сохраняется для учебного разбора истории.

При смене заголовка опубликованная карточка возвращается на проверку. Тест
«Лиловый конструктор» проверяет этот переход и сохранение предыдущего заголовка.
Это вымышленное правило упражнения, а не описание реального продукта.

Непонятный переход обсуждается с наставником команды на схеме состояний.
