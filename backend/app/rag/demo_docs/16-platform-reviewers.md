# Платформа объявлений: кого звать на ревью

Внутренняя синтетическая договорённость команды «Платформа объявлений».

## Кого звать на ревью
Первые учебные PR ревьюит твой наставник. Когда изменение касается схемы
состояний карточки, добавь второго ревьюера: участника команды, который ведёт тему
каталога, его подскажет наставник. Руководителя команды на учебное ревью не зовут.

## Сколько ждать ревью
Обычно первое ревью приходит в течение рабочего дня. Если ответа нет дольше, напиши
ревьюеру в канале команды со ссылкой на PR. Пока ждёшь, бери следующий пункт плана.
