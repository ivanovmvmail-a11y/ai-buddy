# Показ первой задачи в Платформе объявлений

Внутренний учебный чек-лист синтетической команды.

## Что показать на показе первой задачи

1. Подготовь карточку «Картонный дирижабль» в учебном каталоге.
2. Покажи, какое условие задачи раньше не выполнялось.
3. Продемонстрируй создание карточки, поиск по заголовку и перевод в архив.
4. Объясни выбранную проверку ошибок и покажи результат тестов.
5. Запиши замечания наставника и договорись о следующем шаге.

Для демонстрации используются только вымышленные объявления. Учебный стенд
можно сбросить после встречи; подтверждение сброса даёт ответственный за стенд.
