# MCP-сервер (зона Codex)

Здесь будет MCP-сервер с инструментами к **мок-версиям корпоративных сервисов**
(трекер задач, вики, календарь, справочник сотрудников / наставник). Конкретный список определим по ТЗ.

Агент (`app/agent/`) будет вызывать эти инструменты. Интерфейс инструментов сначала описываем
в `docs/API.md` (PR с пометкой `[API]`), потом реализуем.
